# The html5lib tree-construction tests

The `.dat` files here are the HTML parser tree-construction tests begun by
the html5lib project and now kept in web-platform-tests, copied unchanged
from `html/syntax/parsing/resources/` of
https://github.com/web-platform-tests/wpt at commit `30d4d7d`, fetched
2026-10-07.
